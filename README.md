# VkToolRunBMWBT

**VkToolRunBMWBT** — настольное приложение на C# с графическим интерфейсом Windows Forms (.NET 8.0), предназначенное для автоматизации запуска и проведения тестирования производительности компьютера с использованием Wukong: Benchmark Tool (Black Myth: Wukong).

Проект разработан в рамках выполнения тестового задания на стажировку.

## Основные возможности

- **Автоматизация запуска бенчмарка** — запуск тестирования через пользовательский интерфейс приложения.
- **Сбор показателей производительности** — получение данных о результатах тестирования CPU и GPU.
- **Отображение FPS** — передача и визуализация информации о количестве кадров в секунду.
- **Интеграция с Benchmark Tool** — взаимодействие приложения с внешним инструментом тестирования.
- **Графический интерфейс** — управление процессом тестирования и просмотр полученных результатов в Windows Forms.

## Используемые технологии

- **Язык программирования:** C#
- **Платформа:** .NET 8.0
- **Интерфейс:** Windows Forms (WinForms)
